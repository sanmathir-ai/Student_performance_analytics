Student Performance Analytics System

1. Project Overview

The Student Performance Analytics System is a Python-based project developed to analyze student academic performance using NumPy and Pandas.

It calculates student totals, averages, grades, pass/fail results, and identifies top and lowest performers.

2. Objective

- To analyze student marks.
- To calculate total and average marks.
- To assign grades based on average marks.
- To identify pass and fail students.
- To perform subject-wise performance analysis.
- To identify top and lowest-performing students.

3. Technologies Used

- Python
- NumPy
- Pandas
- Visual Studio Code

4. Dataset Description

The project uses a CSV dataset named "students.csv" containing 20 student records.

The dataset includes:

- Student ID
- Name
- Department
- Python marks
- Mathematics marks
- English marks
- Attendance

5. Project Features

- Load student data using Pandas.
- Calculate total marks using NumPy.
- Calculate average marks.
- Assign grades to students.
- Check pass/fail results.
- Find the highest and lowest performers.
- Calculate subject-wise averages.
- Calculate overall class average.

6. Grading Criteria

Average Marks| Grade
90 and above| A+
80–89| A
70–79| B
60–69| C
50–59| D
Below 50| F

A student passes if they score at least 40 marks in every subject.

7. Project Files

- "main.py" – Main Python program.
- "functions.py" – Reusable calculation functions.
- "students.csv" – Student dataset.
- "README.md" – Project documentation.

8. Execution

Run the following command in the terminal:

"python main.py"
